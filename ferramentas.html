[Dashboard] Busca no Dicionário Informal – Dez/2025

Interface interativa de alta performance desenvolvida para o GREMD-USP, projetada para otimizar a extração e análise de dados morfológicos. Originalmente concebido no Looker Studio, o projeto migrou para uma aplicação personalizada em Streamlit, permitindo o uso de Expressões Regulares (Regex) para filtragem automatizada de prefixos, sufixos e radicais diretamente no navegador.
